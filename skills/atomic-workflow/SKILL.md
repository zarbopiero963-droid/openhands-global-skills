# atomic-workflow

Operate one certified card and one PR at a time unless owner explicitly changes scope. Capture baseline SHA, requirements, acceptance criteria, tests and rollback. Distinguish DOCUMENTED, IMPLEMENTED, TESTED, CERTIFIED. Stop on owner decision, missing authorization or ambiguous scope.

## Certification status
PREPARED — NOT CERTIFIED. Verify actual skill discovery and execution in OpenHands against only the authorized test repository. Record positive and negative tests, evidence, costs and owner decisions.
