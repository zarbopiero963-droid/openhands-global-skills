# Atomic certification protocol

For each of the ten skills create one independent card with: ID, exact commit SHA, requirements, environment, authorization, test commands, expected oracle, observed output, negative tests, cost/usage delta, evidence links, cleanup, residual risks and verdict (PASS/FAIL/BLOCKED/NON VERIFICABILE).

Sequence: static schema validation -> discovery in OpenHands -> invocation in authorized test repository -> negative owner-approval test -> logging/recovery -> cost review -> owner acceptance. Do not test on Pickfair, MatchPilot, Betfair LIVE or production resources without new authorization. One card at a time; no blanket 100% claims.
